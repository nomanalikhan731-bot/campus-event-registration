# Campus Event Registration System

## Project Description
A JavaScript-based application for managing campus workshop registrations.

## Project Modules

- main.js: Starts the application.
- Registration.js: Defines the Registration class.
- RegistrationService.js: Handles registration, validation, duplicate checking, listing and searching.
- ConsoleUI.js: Handles user input and output.

## Features
- Register students.
- Validate required fields.
- Prevent duplicate registration numbers.
- Display all registrations.
- Search by registration number.

## Technology
JavaScript and Node.js.

## Run the Application
node main.js
